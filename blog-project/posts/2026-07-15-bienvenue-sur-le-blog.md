# Bienvenue sur le blog automatique

Ceci est un **article de démonstration**. Dès que la clé API Groq sera
configurée, ce blog va commencer à publier automatiquement de nouveaux
articles chaque jour, sans aucune intervention manuelle.

## Comment ça marche

Un script Python interroge une API d'intelligence artificielle gratuite,
récupère un article complet, et l'ajoute directement au site. Un second
script reconstruit ensuite les pages HTML.

## Et la suite ?

Une fois la clé API et GitHub Pages configurés, ce post de démonstration
sera simplement noyé au milieu des vrais articles générés automatiquement.
